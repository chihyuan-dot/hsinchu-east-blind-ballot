# 東區議員盲測選票

新竹市 2026 年市議員選舉第一選舉區（東區）的盲測小測驗。12 道選擇題，選項來自參選人實際提過的政見、議會提案與質詢內容；姓名、黨籍、年齡、性別、經歷全部遮住，作答完才揭曉最接近你的參選人，每條政見都附原始出處連結。

線上試玩：https://chihyuan-dot.github.io/hsinchu-east-blind-ballot/
